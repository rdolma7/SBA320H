With this application, a user will have to login to get access to the Page where they can access the countries exchanges rates with USD being the base.
Technologies used:
REACT, NETLIFY, JS, BrowserRouter, HTML, CSS
Approach taken: First I installed the dependencies, and created a components, helpers and pages folders. And then created the access to the API and the browser router to connect the routes between the folders/files.

Login is the landing page and you get to the currencies page once you click on Login after filling in the required information.
